\# Système IA Responsable et Conforme au RGPD



Application web de gestion de données conforme au RGPD,

développée dans le cadre du cours Éthique et Droit Numérique — ENSA Béni Mellal.



\## Fonctionnalités

\- Gestion des consentements utilisateurs

\- Journalisation des accès (audit log)

\- Conformité RGPD : droit à l'effacement, portabilité des données



\## Technologies

Python, Flask, SQLite



\## Lancer l'application

```bash

pip install flask

python app.py

```
