# Système IA Responsable et Conforme au RGPD



Déploiement d’un système d’IA interne et conforme au RGPD 


## Fonctionnalités

\- Gestion des consentements utilisateurs

\- Journalisation des accès (audit log)

\- Conformité RGPD : droit à l'effacement, portabilité des données



## Technologies

Python, Flask, SQLite



## Lancer l'application

```bash

pip install flask

python app.py

```
